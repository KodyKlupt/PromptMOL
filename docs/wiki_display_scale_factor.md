# Display scale factor

The display_scale_factor setting scales the internal gui, the internal prompt, label fonts etc. by a multiple of 1. The setting was introduced to scale by a factor of 2 on high resolution 4K Retina displays.

- New in Incentive PyMOL 1.8.4*

##  Usage
- **--retina** command line option sets the factor to 2
- MacPyMOL menu: **Display > Retina Resolution** sets the factor to 2

##  Example
 set display_scale_factor, 2
