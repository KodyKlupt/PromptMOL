# Internal gui mode

= Overview =
This sets how PyMOL renders the internal GUI & controls.  The default setting, 0.

Image:Ig_mode0.png|internal_gui_mode, set to 0
Image:Ig_mode1.png|internal_gui_mode, set to 1.  Notice the coloring under the controls.

= Syntax =

```python
1. set to 0 or 1
set internal_gui_mode, int

1. for example, put it in mode 1
set internal_gui_mode, 1
```
