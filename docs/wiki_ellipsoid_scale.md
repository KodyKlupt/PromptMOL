# Ellipsoid scale

= Overview =
This sets the relative scale of drawing Ellipsoids.  Larger numbers make larger ellipsoids.

= Syntax =

```python
1. set to some real valued size
set ellipsoid_scale, float

1. for example, magnify the ellipses
1. by drawing them 1.4x their normal size
set ellipsoid_scale, 1.4
```
