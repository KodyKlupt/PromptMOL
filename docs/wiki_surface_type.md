# Surface type

= Overview =
- *Surface_type** sets the type (dots, filled triangles, empty triangles) of the surface that PyMOL will render.

= Syntax =

```python
set surface_type, typeNumber  # typeNumber = [1..3]
```

= Examples =

```python
set surface_type, 2
```

Image:st0.png|surface_type, 0  # usual
Image:st1.png|surface_type, 1  # dots
Image:st2.png|surface_type, 2  # triangles
Image:st3.png|surface_type, 3  # is this the same as surface_type 0?
