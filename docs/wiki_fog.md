# Fog

##  Overview
set fog allows Depth Cue (or fog!) to be turned on or off in the interactive viewer, not for ray traced images, for this see Ray_Trace_Fog

##  Syntax
```python
1. turn off the fog
set fog, off
set fog, 0

1. turn on the fog
set fog, on
set fog, 1
```
