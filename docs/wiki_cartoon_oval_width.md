# Cartoon oval width

##  Overview
Only relevant when oval (default) helices is turned on, see Cartoon_Helix_Settings
set cartoon_oval_width defines the width of the helix

##  Syntax
```python
set cartoon_oval_width,         #default setting is 0.25
```
