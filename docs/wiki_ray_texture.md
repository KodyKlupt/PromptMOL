# Ray texture

##  Overview
- *ray_texture** sets what texture PyMol applies to the surface of your object during ray tracing.  Options now consist of
1. None
1. Matte 1
1. Matte 2
1. Swirl 1
1. Swirl 2
1. Fiber

##  Usage
```python
set ray_texture, X      # where X = 0 ... 5
```
