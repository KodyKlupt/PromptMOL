# Cartoon putty scale max

= Overview =
cartoon_putty_scale_max sets the max scale that PyMOL will use for rendering cartoon putty.

= Usage =

```python
1. set a max scale
set cartoon_putty_scale_max, 3

1. no limits on scaling
set cartoon_putty_scale_max, -1
```
