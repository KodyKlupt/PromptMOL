# Replace

- *replace** replaces the picked atom with a new atom.

### USAGE
 replace element, geometry, valence [,h_fill [,name ]]

### PYMOL API
```python
cmd.replace(string element, int geometry, int valence,
            int h_fill = 1, string name = "" )
```
