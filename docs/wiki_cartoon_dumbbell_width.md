# Cartoon dumbbell width

##  Overview
Only relavent when fancy helices is turned on, see Cartoon_Helix_Settings
set cartoon_dumbbell_width defines the width of the helix when the fancy helices setting has been engaged

##  Syntax
```python
set cartoon_dumbbell_width,         #default setting is 0.1
```

Adjust this value or that of cartoon_dumbbell_radius to remove the bulge at the edges of a fancy helix
