# Cartoon rect width

##  Overview
set cartoon_rect_width adjusts thickness of the cartoon representation of sheets

##  Syntax
```python
set cartoon_rect_width,                  #default 0.4
```

##  Example

Image:cartoon_rect_width_default.png|cartoon_rect_width 0.4 (default)
