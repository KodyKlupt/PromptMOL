# Cartoon oval length

##  Overview
Only relevant when oval (default) helices is turned on, see Cartoon_Helix_Settings
set cartoon_oval_length defines the length between the edges of the cartoon ribbon

##  Syntax
```python
set cartoon_oval_length,         #default setting is ~1.35
```
