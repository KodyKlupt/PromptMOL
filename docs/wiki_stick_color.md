# Stick color

##  Overview
- Stick_color* controls the color of sticks for a selection or object.  For example, one could color all atoms by their element as transparent spheres, but for a nice underlying structure, have all the sticks shown in marine.

##  Syntax
```python
set stick_color, color
```
